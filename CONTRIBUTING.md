# Contributing to SciOly Cheat Sheet Generator

First off, thank you for considering contributing to this project! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## Contributor License Agreement (CLA)

We love community contributions! However, to legally protect the project and ensure we can continue to distribute and potentially commercialize this tool in the future, we require all contributors to sign a Contributor License Agreement (CLA).

**You do not need to do anything manually right now.**

When you submit your first Pull Request, a bot (CLA Assistant) will automatically comment on your PR with a link. You simply click the link, sign in with your GitHub account, and click "I Agree". Once you agree, the bot will automatically approve your PR for review!

## Branching Strategy

Please follow this workflow when submitting changes:

1. **Fork the repository** to your own GitHub account.
2. **Create a new branch** from `dev` (e.g., `feature/add-new-export-format` or `bugfix/fix-rag-error`).
3. Make your changes in your branch.
4. **Submit a Pull Request** targeting the `dev` branch of this repository. **Do not target `main`.**

## What to Contribute

- **Bug Fixes:** Notice an API error or a formatting glitch? We'd love a fix!
- **New Features:** Ideas for new AI agents, better PDF formatting, or GUI wrappers are always welcome.
- **Prompt Engineering:** If you find a way to rewrite the system prompts in the Architect or Compiler to generate even denser/better text, please submit it!

## Running Tests

If you add new functionality, please ensure it runs smoothly with the existing pipeline.

Once again, thank you for your help in making this the ultimate tool for the Science Olympiad community!
